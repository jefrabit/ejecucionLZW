Fundamentos de Compresión

La compresión de datos consiste en representar información usando menos bits mediante la eliminación de redundancia.

Objetivos principales:

  • Reducir requisitos de almacenamiento
  • Minimizar ancho de banda en transmisión
  • Acelerar transferencia de datos

Relación de Compresión:

\[ RC = \frac{Tamaño\ original}{Tamaño\ comprimido} \]

Ejemplo: Archivo de 100MB → 25MB comprimido

\( RC = \frac{100}{25} = 4:1 \)

Redundancia de Datos

La compresión se basa en identificar y eliminar tres tipos de redundancia:

1. Redundancia Estadística

Distribución no uniforme de símbolos

Símbolo A: Frecuencia 80%
Símbolo B: Frecuencia 10%
Símbolo C: Frecuencia 5%
Símbolo D: Frecuencia 5%

2. Redundancia Espacial/Temporal

Patrones repetitivos en datos

"ABABABABAB" → "5(AB)"

3. Redundancia Psicológica

Información imperceptible para humanos

(Compresión con pérdida)

Entropía de la Información

Concepto fundamental de la teoría de la información desarrollado por Claude Shannon

\[ H(X) = - \sum_{i=1}^{n} P(x_i) \log_2 P(x_i) \]

Donde:

  • \( H(X) \) = Entropía de la fuente \( X \) (en bits)
  • \( P(x_i) \) = Probabilidad del símbolo \( x_i \)
  • \( n \) = Número de símbolos posibles

Interpretación de la Entropía

Ejemplo 1: Fuente de 2 símbolos

Símbolos: A, B con P(A) = 0.5, P(B) = 0.5

\[ H(X) = -[0.5 \cdot \log_2(0.5) + 0.5 \cdot \log_2(0.5)] \] \[ H(X) = -[0.5 \cdot (-1) + 0.5 \cdot (-1)] = 1 \text{ bit} \]

Máxima entropía → Mínima compresibilidad

Ejemplo 2: Fuente sesgada

Símbolos: A, B con P(A) = 0.9, P(B) = 0.1

\[ H(X) = -[0.9 \cdot \log_2(0.9) + 0.1 \cdot \log_2(0.1)] \] \[ H(X) \approx -[0.9 \cdot (-0.152) + 0.1 \cdot (-3.322)] \] \[ H(X) \approx 0.469 \text{ bits} \]

Baja entropía → Alta compresibilidad

Límite Teórico de Compresión

Según el teorema de codificación de fuente de Shannon:

\[ L \geq H(X) \]

Donde \( L \) es la longitud promedio del código

Para una fuente con entropía \( H(X) \), es imposible crear un código con longitud promedio menor que \( H(X) \) bits por símbolo.

Eficiencia del código: \( \eta = \frac{H(X)}{L} \)

Codificación de Huffman

Algoritmo voraz que construye códigos de prefijo óptimos

Pseudocódigo:

  1. Calcular frecuencia de cada símbolo
  2. Crear nodo hoja para cada símbolo
  3. Repetir hasta tener un solo nodo:
    • Seleccionar dos nodos con menor frecuencia
    • Crear nodo padre con frecuencia = suma
    • Asignar 0 a rama izquierda, 1 a derecha
  4. El código de cada símbolo es el camino desde la raíz

Algoritmo LZW

Compresión por diccionario que construye tablas dinámicamente

Funcionamiento:

  1. Inicializar diccionario con símbolos individuales
  2. P = primer carácter de entrada
  3. Mientras haya caracteres por leer:
    • C = próximo carácter
    • Si P+C está en diccionario:
      • P = P+C
    • Si no:
      • Emitir código para P
      • Agregar P+C al diccionario
      • P = C
  4. Emitir código para P

Ejemplo: Comprimir "ABABABA"

Entrada Salida Nueva entrada
A 65 256: AB
B 66 257: BA
AB 256 258: ABA
ABA 258 -
Entrada: "ABABABA" → Salida: 65, 66, 256, 258

Algoritmos Con Pérdida

Eliminan información considerada menos importante basándose en modelos perceptuales

Principios:

  • Explotar limitaciones del sistema perceptual humano
  • Transformar datos al dominio de frecuencia
  • Cuantización: reducir precisión de coeficientes
  • Codificación entrópica de los resultados

Transformaciones comunes:

  • DCT (Discrete Cosine Transform)
  • Wavelet Transform
  • MDCT (Modified Discrete Cosine Transform)

Algoritmo JPEG

Estándar para compresión de imágenes fotográficas

Proceso de compresión:

  1. Conversión de RGB a YCbCr
  2. Submuestreo de croma (reducir resolución de color)
  3. Aplicar DCT a bloques 8x8
  4. Cuantización de coeficientes DCT
  5. Codificación entrópica (generalmente Huffman)

Transformada Discreta del Coseno (DCT):

\[ F(u,v) = \frac{1}{4} C(u)C(v) \sum_{x=0}^{7} \sum_{y=0}^{7} f(x,y) \cos\left[\frac{(2x+1)u\pi}{16}\right] \cos\left[\frac{(2y+1)v\pi}{16}\right] \]

  • Construcción del árbol: O(k log k)
  • Codificación: O(n)
  • Decodificación: O(n)

  • n = longitud del mensaje

  • Compresión: O(n)
  • Descompresión: O(n)
  • Uso de tabla hash para búsquedas O(1)
  • Memoria: O(m) para el diccionario

Límites y Futuro

Desafíos y tendencias en compresión de datos

Límites Teóricos:

  • Límite de Shannon: \( L \geq H(X) \)
  • Compresión sin pérdida tiene límite inferior
  • Datos aleatorios son incompresibles

Tendencias Actuales:

  • Compresión neuronal
  • Algoritmos específicos por dominio
  • Compresión en tiempo real para streaming

Conclusiones

Puntos Clave:

  • La compresión se basa en eliminar redundancia
  • La entropía define el límite teórico de compresión
  • Huffman es óptimo para códigos de prefijo
  • LZW aprovecha repeticiones en los datos
  • JPEG usa transformadas y cuantización
